2026-09-11：新增 26 个订阅，连同保留的 24 个预设，目录共 50 个。这里的单位是 RSS/Atom 订阅，不是 50 家独立媒体。产品仍是通用新闻工具；不采用家电、海尔或暖通行业主题、评分权重、关键词和事件族。

## 在产品中使用

在“来源”页选择“银行与金融 · 全部”，可进一步按四类或来源名称、网址搜索。列表筛选不等于启用，也不改变主题的来源绑定。用户按需启用后，在主题中选择这些来源；主题绑定为空时仍按原约定使用所有已启用来源。

新预设全部默认关闭。已有用户改过的名称、地址、分类、语言、启停和移除状态不覆盖；主题词、门槛、数量、历史、收藏、来源绑定与 Key 不因扩充目录而更改。数据库和备份仍为 schema v2。Catalog v3 是来源包版本，不是应用 3.0；本次随 1.3.0 候选版交付。

## 验证标准与限度

逐条以原应用客户端运行 RSS 文档审计和生产 FeedService：HTTPS、有效 RSS/Atom、5 MiB 上限、公开无需登录；前 20 条标题/链接/日期完整，最新内容在最近 60 天内。日期门槛是来源健康检查，不代表自动改动用户默认的最近 7 天新闻窗口。低频公告源可能在 7 天内没有新增；澳央行两条源本次各返回一条。

可重复执行只读审计：

```bash
PYTHONPATH=src python scripts/audit_source_presets.py --category banking_all --output artifacts/banking-audit.json
PYTHONPATH=src python scripts/audit_source_presets.py --source-id preset-hkma-press-zh
```

不传过滤参数时审计完整当前目录，不再只检查旧 v2 的八条。离线测试使用固定 RSS/Atom 夹具，不依赖真实新闻网站。

## 权利、偏差与隐私

公开 RSS、可访问网页或隐私政策不是任意商用/转载/AI 使用的许可。本次记录官方目录和条款入口，并非法律合规认证。部分来源仅允许个人或内部非商业使用并要求署名，使用者需要按自己的用途查看网站条款；如需对外发布、商业分发或其他受限用途，应确认相应授权。

启用 DeepSeek 会把候选文本发到其云端；可在设置关闭 AI 或全文补抓，但关闭某一个功能不自动意味着所有用途都获许可。应用仍提供个人本地阅读、来源链接和摘要；不提供全文再分发服务。

香港政府、港台财经不是纯银行专栏；Fintech Singapore 含赞助内容；央行讲话和监管通告常是机构立场或政策文件，不应当作独立市场报道。扩大覆盖不保证数量，也不自动提高文章得分。来源可用性、更新频率和条款都会变化，当前一次通过不能保证每个网络或未来永久可用。

本次未对旧 24 条预设进行新的授权审计，也未因银行来源包删除用户的原有来源。部分参考页对自动探针返回 403（如澳央行、CFPB），但订阅本身两条路径成功；参考网页可访问性与 Feed 健康分开记录。
